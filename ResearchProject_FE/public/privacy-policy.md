# Privacy Policy for Reactive Web Extension

Last updated: [Current Date]

## Introduction
Reactive Web is a Chrome extension that provides content analysis and UI personalization for Medium articles. This privacy policy explains how we handle data in our extension.

## Data Collection
Our extension collects the following data:

### Website Content
- Medium article content for:
  - Generating summaries
  - Creating mind maps
  - Enabling chat functionality
  - Applying UI personalization

### User Preferences
- UI customization settings
- Content display preferences
- Feature preferences

## How We Use Data
1. **Content Analysis**
   - Process article content to generate summaries
   - Create mind maps from article structure
   - Enable chat functionality about the article

2. **UI Personalization**
   - Apply user preferences to article display
   - Customize reading experience
   - Save user settings

## Data Storage
- All data processing is done through our secure backend services
- User preferences are stored locally in the browser
- No personal data is stored on our servers

## Data Sharing
- We do not sell or transfer user data to third parties
- We do not use data for purposes unrelated to the extension's functionality
- We do not use data for creditworthiness or lending purposes

## Security
- All data transmission is encrypted
- We use secure backend services hosted on Render.com
- We implement industry-standard security measures

## User Rights
Users can:
- Clear their stored preferences
- Disable the extension at any time
- Request information about their data
